
Embedded server requirements

Install missing or incompatible dependencies in the host package:
npm install '@orpc/server@1.14.3' '@t3-oss/env-core@0.13.11' 'drizzle-kit@1.0.0-beta.22' 'typebase-io@0.1.0' 'zod@*'
npm install -D '@types/node@24.1.0' '@types/pg@8.20.0' 'typescript@5.9.3'

Required Environment keys: DATABASE_URL
Load these in your host before importing the embedded server.

Cross-origin headers are your host application's responsibility. Configure its CORS policy for your clients.

Mount from your project root (adjust the import for your entry point):
import { typebaseHandler } from "./host/src/typebase/src/server.js";

// In your existing Express application:
app.use(typebaseHandler);

Dependency and environment details: host/src/typebase/typebase-server.json
