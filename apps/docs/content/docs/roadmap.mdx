These are the things we're actively working on for the next release, roughly in the order they'll land. The list isn't exhaustive (smaller improvements ship along the way), but it should give you a sense of where Typebase is heading.

## v0.2.0

- Add storage support.
- Add mailer support.
- Realtime queries.
- Add watch mode to generate-server command.

## v0.3.0

- Allow users to use migrations.
- Allow users to add oRPC plugins (client and server).
- Assign custom domains to deploys (staging and production).
