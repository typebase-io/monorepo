## `auth generate`

Add authentication tables to your database schema.

```npm
npx typebase-io-cli auth generate
```

This command:

1. Reads your `auth.ts` configuration
2. Generates the required tables (`users`, `sessions`, `accounts`, `verifications`)
3. Appends them to `db/schema.ts`
4. Updates `db/relations.ts`
5. Generates and saves `BETTER_AUTH_SECRET` in your local `.env` if it doesn't already exist
6. Regenerates type definitions

### Prerequisites

- A `typebase/auth.ts` file must exist
- A `typebase/db/schema.ts` file must exist

### In migrations mode

If your project uses [migrations](/docs/database/migrations), `auth generate` also records a migration for the tables it just added:

```
✔ Auth tables added to schema.ts and relations.ts.
✔ Migration written to typebase/db/migrations/20260101120000_auth_tables.
```

`auth generate` is one of the few commands that edits your schema for you, and what it adds is known and bounded, so it records the migration itself
rather than leaving your schema files and your history to drift apart. Re-running it when the auth tables are already there and unchanged records
nothing.

See the [Authentication](/docs/auth) page for full details on setting up auth.
